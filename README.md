> An immersive, celestial liquid glass web experience crafted for birthday celebrations, combining interactive particle animations, ambient background music, custom photo memories gallery, and heartfelt lyrical poetry.

---

## 🌌 Key Highlights & Visual Features

1. **Celestial Liquid Glass Aesthetic**
   - High-contrast, ambient dark theme with translucent glassmorphic surfaces, dynamic backdrop blurs, and luminous celestial glows.
   - Fluid typography and responsive interactive motion designed for both desktop and mobile screens.

2. **Interactive Photo Memories & Carousel**
   - Elegant media showcase celebrating personal milestones with smooth transition physics.
   - Custom card layouts for dedications, quotes, and wishes.

3. **Ambient Audio & Media Controller**
   - Integrated soundtrack controller with ambient audio playback and responsive visualizer effects.
   - Micro-interactions, celebratory confetti bursts, and personalized greeting reveals.

## 🚀 Getting Started

### 1. Installation
```bash
git clone https://github.com/abhisheikraja2007-droid/Astra-Happy-Birthday-Experience.git
cd Astra-Happy-Birthday-Experience
npm install
```

### 2. Development Server
```bash
npm run dev
```
Open `http://localhost:5173` to explore the celestial birthday experience.

### 3. Production Build
```bash
npm run build
npm run preview
```
